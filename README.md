# 🧪 Development Branch — Online Grocery Ordering System

Welcome to the **Development Branch** of the Online Grocery Ordering System.  
This branch is dedicated to **active development, new feature integration, bug fixes, testing**, and workflow setup before merging to the **main** production branch.

---

## 🎯 Purpose of This Branch

The `dev` branch serves as the working environment for:

- 🚧 Feature development & enhancement
- 🐞 Bug fixing & debugging
- 🧩 Integration of UI + Backend modules
- 🔄 API testing & database validation
- 📦 Docker build checks & AWS prep
- ✅ Code Review & PR validation

This ensures the `main` branch remains **stable & production-ready**.

---

## 🛠️ Tech Stack (In Dev)

### **Frontend**
- React.js (with Hooks)
- Axios for API calls
- Tailwind / Bootstrap UI styling
- React Router

### **Backend**
- Spring Boot
- REST API
- Spring Data JPA
- JWT & Spring Security *(if configured)*

### **Database**
- MySQL / PostgreSQL (local + cloud integration)

### **DevOps**
- Git + GitHub version control
- Docker container testing
- AWS deployment staging checks
