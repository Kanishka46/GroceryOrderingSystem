# 🛒 Online Grocery Ordering System

A full-stack **Online Grocery Ordering System** that provides a seamless grocery shopping experience with secure login, product browsing, cart management, and online order placement.

This project demonstrates modern full-stack development using **React (Frontend)**, **Spring Boot (Backend)**, **SQL Database**, **AWS Deployment**, and **Docker Containerization**.
